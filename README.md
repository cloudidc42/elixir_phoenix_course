# หลักสูตร Elixir & Phoenix Framework

## จากระดับพื้นฐานสู่ระดับโลก

หลักสูตรนี้ออกแบบมาเพื่อพาคุณเดินทางจากการเริ่มต้นใช้ Elixir จนถึงการพัฒนาระบบ Production ระดับมืออาชีพ

---

## โครงสร้างหลักสูตร

### ภาค 1: พื้นฐาน Elixir (Part 01-20)
- การติดตั้งและตั้งค่า
- ไวยากรณ์พื้นฐาน
- โครงสร้างข้อมูล
- Pattern Matching
- Functions และ Modules

### ภาค 2: Elixir กลาง (Part 21-40)
- Processes และ Concurrency
- OTP: GenServer, Supervisor
- Error Handling
- Testing
- Metaprogramming

### ภาค 3: Phoenix Framework พื้นฐาน (Part 41-60)
- การติดตั้ง Phoenix
- MVC Architecture
- Routing และ Controllers
- Templates และ Views
- Ecto และ Databases

### ภาค 4: Phoenix ขั้นสูง (Part 61-80)
- LiveView
- Channels และ WebSockets
- Authentication
- API Development
- File Uploads

### ภาค 5: ระดับมืออาชีพ (Part 81-100+)
- Performance Optimization
- Deployment และ DevOps
- Distributed Systems
- Security
- Real-world Projects
